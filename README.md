# Decentralized Marketplace on Ergo

Neutral, permissionless infrastructure for trade.

## The documents

- **[VISION.md](VISION.md)**: what this is, why it exists, who it's for, the hard problems, the economic model, and how to get it off the ground. Start here.
- **[DESIGN.md](DESIGN.md)**: the full technical specification, the contract family, the escrow state machine, parameter and bond economics, the mediator and reputation mechanisms, the connective and application layers, a risk register, and worked transaction examples.

This is an early-stage design, written to attract builders and feedback. It is not a finished product.

AI was used for consolidation of notes and finding gaps.
